# IAT460_DJPal_Final_Project

DJ Pal is a generative AI system that can transform any song into a new genre. DJ Pal uses Python, Librosa, Hybrid Demucs, MusicGen, and Gradio to achieve this.

How to Run:
1. Download the ipynb file and open in your chosen application.
2. Run all cells in the notebook (includes required installations).
3. Open the Gradio link outputted in the final notebook cell to access DJ Pal.
4. Upload any song and get remixing!



DJ Pal Requirements:
-librosa
-demucs
-pydub
-soundfile 
-torch
-torchaudio
-setuptools wheel
-HuggingFace transformers
-gradio
-matplotlib
-os
-numpy
-scipy
